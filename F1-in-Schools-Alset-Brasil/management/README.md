# 📊 Project Management & Strategy

This folder documents the strategic planning and organizational framework used to lead the **Rise 5** project to completion.

## 📌 Key Management Pillars
* **WBS (Work Breakdown Structure):** A detailed breakdown of the project phases, from R&D to final manufacturing.
* **Budgeting:** Strategic resource allocation to ensure technical feasibility within competition constraints.
* **Team Onboarding:** Training protocols for new engineering members.
